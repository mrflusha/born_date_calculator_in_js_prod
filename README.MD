## 🧭 О проекте
Сервис, который поможет вам узнать идеальную дату рождения вашего ребенка. Просто введите предполагаемую дату зачатия, и наш алгоритм рассчитает наиболее благоприятный день для появления малыша на свет. С нашим сервисом вы сможете выбрать дату рождения, которая принесет вашему ребенку удачу и счастье.



## 🚀 Как запустить
Работает directly во ВКонтакте — установка не требуется.
